# มุมมองป้ายรีล SMT และเส้นสายตา

หน้า HTML ล้วน สำหรับดูแบบร่างด้านหน้า ด้านข้าง และเส้นสายตาของป้ายรหัสบนรีล SMT ในกล่อง ESD

เปิดแล้วจะได้

- รูปกล่องรีลอ้างอิง
- มุมสายตาตรง 0° จากแนวราบ
- ตารางความสูงขั้นต่ำของป้าย 4 แถว เมื่อมองตรง (แถว 1 = Ø รีล แถวถัดไปสูงขึ้นทีละ S)
- มุมมองด้านหน้า (2 แถวซ้าย–ขวา × 4 แถวลึก) และด้านข้างพร้อมเส้นสายตา
- ภาพ SVG ที่อัปเดตตามสไลเดอร์
- ปุ่ม **ส่งออก HTML** ดาวน์โหลดรายงานไฟล์เดียว (ตารางมุม ความสูง ค่าที่ใช้คำนวณ และแบบร่างด้านหน้า/ด้านข้าง) เปิดได้โดยไม่ต้องมีเซิร์ฟเวอร์

ค่าตั้งต้นใช้รีล 7 นิ้ว (Ø 178 มม.) และมุมสายตาตรงที่ระดับยอดป้ายแถว 1 ปรับสไลเดอร์ให้ตรงของจริงในไลน์ได้

## วิธีเปิด

เปิดไฟล์ตรงๆ

```bash
# macOS
open index.html

# Linux
xdg-open index.html
```

หรือเสิร์ฟแบบ static (แนะนำ ถ้าเบราว์เซอร์บล็อกรูปจากไฟล์ท้องถิ่น)

```bash
python3 -m http.server 43123
```

แล้วเปิด [http://127.0.0.1:43123](http://127.0.0.1:43123)

ไม่ต้องติดตั้ง Node หรือแพ็กเกจใดๆ

กด **ส่งออก HTML** ที่แถบตั้งค่า จะได้ไฟล์ `smt-reel-sightline-….html` ในโฟลเดอร์ดาวน์โหลด เปิดไฟล์นั้นตรงๆ ได้เลย เพราะฝังรูปและ SVG ไว้ในไฟล์แล้ว

ถ้าจะย้ายทั้งโปรเจคไปเครื่องอื่น กด **ดาวน์โหลดโปรเจค (.zip)** หรือเปิด [smt_reel_sightline.zip](./smt_reel_sightline.zip) แล้วแตกไฟล์ จะได้ `index.html`, `README.md` และ `assets/reel-tote.png`

## สูตร

เกณฑ์หลักคือสายตาตรง ไม่ใช่มุมก้ม

ไล่ระดับแบบอัฒจันทร์ (สนามบอล / คอนเสิร์ต)

- ป้ายแต่ละแถวใบเท่ากัน ไม่ดึงแผ่นยาวจากยอดรีล
- แถว 2 ใช้ระยะแรกใหญ่กว่าและปรับได้กว้าง (สูง + ลึก)
- แถว 3–4 ไล่ด้วยค่า `C` เล็กกว่า

```
θn = arctan((He − hn) / Dn)
h1 = ขอบบนรีล
ไล่ระดับ: hn = ขอบบนรีล + (n − 1) · C
เยื้องป้าย: hn = ขอบบนรีล + C
```

- `θn` มุมจากแนวราบถึงยอดป้ายแถวนั้น บวก = ก้ม ลบ = เงย 0° = สายตาตรง
